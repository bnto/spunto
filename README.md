# Spunto

Set up my dev environment on a new computer in a few minutes running this simple command:
`curl https://spu.nto.lu/setup | sh`.

## Requirements

- A terminal
- Command line tools `xcode-select --install`

## Homebrew

Get `Brewfile` list of installed packages: `brew bundle dump --describe`

Install packges form a `Brewfile`: `brew bundle --file ~/Brewfile`
